# 🛒 쇼핑 리스트

Python + Streamlit으로 만든 간단한 쇼핑 리스트 웹 앱입니다. 아이템 추가, 수정, 삭제, 체크 기능을 제공합니다. (요구사항: `prd.md`)

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 로 접속합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | Streamlit 화면 |
| `storage.py` | 데이터 저장·로드와 추가/수정/삭제/체크 함수 (Streamlit 비의존) |
| `data/shopping_list.json` | 아이템 데이터 (실행 중 자동 생성, git 제외) |

## 데이터 저장 관련 주의사항

데이터는 `data/shopping_list.json` 파일에 저장됩니다.

- 여러 탭이나 기기에서 동시에 써도 서로의 변경을 덮어쓰지 않습니다. 다른 기기의 변경은 다음 동작 때 화면에 반영됩니다.
- 데이터 파일이 손상되면 원본을 `data/shopping_list.corrupt-<시각>.json`으로 백업하고, 앱에 경고를 표시합니다.

Streamlit Community Cloud에 배포하면 다음 점에 유의하세요.

- 앱이 재시작·재배포되거나 휴면 후 깨어나면 데이터가 초기화될 수 있습니다.
- 접속한 모든 사람이 같은 리스트를 공유합니다.

## 알려진 한계

- 서로 다른 버튼을 아주 빠르게(0.1초 안에) 연달아 누르면, Streamlit이 실행 요청을 합치면서 앞의 클릭이 무시될 수 있습니다. 엉뚱한 아이템이 바뀌지는 않으며, 다시 누르면 됩니다.
- 같은 내용(이름·수량·메모)을 2초 안에 다시 추가하면 중복 제출로 보고 무시합니다.
- 아이템이 50개를 넘으면 처음 50개만 표시하고, "더 보기"로 이어서 볼 수 있습니다.
